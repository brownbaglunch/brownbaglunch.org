  title: 'Comprendre et maîtriser la performance de vos applications Spark'
  abstract: |
    Apache Spark s'est imposé comme l'outil de prédilection pour développer des applications en tout genre sur les datalakes d'entreprise et dans le cloud mais beaucoup d'équipes n'arrivent pas à obtenir de bonnes performances, par manque d'outillage ou de connaissance du framework.

    Je vous propose de parcourir l'ensemble des bonnes pratiques et techniques que vous pourrez mettre en pratique dans vos propres développements, ainsi que des outils de mesure et d'analyse disponibles dans l'écosystème qui vous permettront de piloter cette performance dans la durée.

    Les exemples de code, dérivés de cas réels, s'appuieront les API Python et SQL de Spark mais ne nécessitent pas de compétence a priori dans ce langage
